# Strakly User Guide

This guide helps users navigate and use the Strakly gym management software.

## Overview

Strakly is a comprehensive gym management system that helps gym owners, managers, trainers, and staff manage their fitness business efficiently.

## User Roles

### Superadmin
- Manages all gyms in the system
- Onboards new gym admins (owners)
- Has access to all gym data

### Admin (Gym Owner)
- Full control over their gym
- Manages branches, staff, clients, and finances
- Creates membership plans and offers

### Manager
- Manages day-to-day operations
- Can manage clients, trainers, and attendance
- Limited access to financial data

### Branch Admin
- Manages a specific branch
- Can manage clients and staff within their branch

### Trainer
- Manages assigned clients
- Creates diet and workout plans
- Tracks client progress

### Client (Member)
- Views their membership details
- Checks attendance history
- Views assigned trainer and diet plans

## Common Tasks

### How to Create a Client/Member

1. Go to **Clients** page from the sidebar menu
2. Click the **"Add Client"** or **"+"** button at the top right
3. Fill in the client details:
   - **Name** (required)
   - **Email** (required)
   - **Phone** (required)
   - **Gender**
   - **Date of Birth**
   - **Address**
4. Click **"Save"** or **"Create"** button
5. The client will be created and you can assign a membership plan

**Alternative: Create from Enquiry**
1. Go to **Enquiry** page
2. Add a new enquiry with prospect details
3. Once converted, click **"Convert to Client"** button
4. The enquiry will be converted to an active client

### How to Add a Membership Plan to a Client

1. Go to **Clients** page

### How to Migrate Data from Another Software

If you're switching from another gym software, you can import your existing data using the Data Migration feature.

**Supported data types:** Members, Staff (Trainers/Managers), Memberships, Payments

**Step-by-step:**

1. Go to **Data Migration** page from the sidebar (Admin and Branch Admin only)
2. Read the migration guide shown on the page
3. **Select data type** — choose what you want to import (Members, Staff, Memberships, or Payments)
4. **Download template** (optional) — click "Template" to get an Excel file with the correct format
5. **Upload your file** — drag & drop or browse for your CSV/Excel file (max 10MB)
6. Click **"Parse & Continue"** to proceed

**Column Mapping:**
7. Review the auto-detected column mappings
8. For each Strakly field, select the matching column from your file using the dropdown
9. Required fields are marked with an asterisk (*)
10. Check the preview table to verify mappings look correct
11. Click **"Continue"**

**Value Mapping:**
12. Review auto-mapped values (e.g., "Active" → "active", "M" → "male")
13. Map any unrecognized values to Strakly equivalents using the dropdowns
14. Click **"Continue"**

**Preview & Import:**
15. Review the validation summary (Total Rows, Valid Rows, Errors)
16. Check the error list — rows with errors will be skipped during import
17. Click **"Import X Rows"** to start the import
18. View the import results (imported, skipped, errors)

**Important notes:**
- **Import order**: Import Members and Staff first, then Memberships and Payments (memberships need existing members, payments need existing members)
- **Duplicate emails are skipped** — existing data won't be overwritten
- **Default password**: Imported members get password "Strakly@123" — they should change it on first login
- **Supported formats**: CSV, Excel (.xlsx, .xls), max 10MB per file

### How to Use the AI Voice Assistant

The Voice Assistant lets you control Strakly hands-free using voice commands. Just say the wake word and speak your command.

**How to activate:**
1. Click the **microphone icon** (🎤) at the bottom-right corner
2. Allow microphone permission when prompted by your browser
3. The assistant will show **"Say 'Hey Strakly'... Waiting for wake word.."**
4. Say **"Hey Strakly"** (or "Hi Strakly", "Hello Strakly") followed by your command

**Wake words (any of these work):**
- "Hey Strakly"
- "Hi Strakly"
- "Hello Strakly"
- "Hey Assistant"
- Just "Strakly"

**Voice states:**
- **Idle** (pulsing ring) — Listening for wake word
- **Listening** (expanding rings) — Wake word detected, waiting for your command
- **Processing** (spinning) — Sending your command to the AI
- **Speaking** (pulsing) — AI is reading the response aloud

**Example voice commands:**
- "Hey Strakly, how do I add a new member?"
- "Hi Strakly, navigate to the clients page"
- "Hey Strakly, change theme to dark"
- "Hello Strakly, what are today's stats?"

**Tips:**
- Speak clearly in a normal voice
- Wait for the "listening" state before saying your command
- The assistant will automatically stop listening after a few seconds of silence
- Click the mic icon again to turn off the voice assistant
- Works best in **Google Chrome** (uses Web Speech API)

**Troubleshooting:**
- **No response to wake word**: Make sure the mic icon is active (showing idle state). Check browser microphone permissions.
- **"Microphone permission denied" error**: Go to browser settings > Site Settings > Microphone and allow access for Strakly.
- **Assistant not hearing you**: Speak closer to the microphone. Reduce background noise.
- **Browser not supported**: Voice assistant requires Chrome or Edge (Chromium-based browsers with Web Speech API support).

## Membership Freeze / Hold

Members can temporarily freeze (pause) their membership when they need a break (travel, injury, etc.).

### How to Freeze a Membership

1. Go to the member's profile > **Membership** tab
2. Click **"Freeze Membership"**
3. Set the **Freeze Start Date** and **Freeze End Date**
4. Enter the **Reason** for the freeze (optional)
5. Click **"Save"**
6. The membership end date will be automatically extended by the freeze duration

**Key details:**
- The membership status changes to **"frozen"** during the freeze period
- Billing is paused during the freeze
- After the freeze end date, the membership automatically resumes
- Each plan has a **Max Freeze Days** setting (e.g., 30 days per year) — the system enforces this limit
- Freeze history is recorded and visible in the membership tab

### Common Issues

**Q: Can a member freeze multiple times?**
A: Yes, as long as the total freeze days don't exceed the plan's max freeze days limit.

**Q: What happens if the member wants to unfreeze early?**
A: Go to their membership tab and click **"Unfreeze"** to end the freeze immediately. The remaining freeze days are returned.

**Q: Does the membership end date extend?**
A: Yes, the end date automatically shifts forward by the number of days frozen.

## Lead / Prospect CRM

Strakly includes a full CRM pipeline for tracking sales leads from initial inquiry through to membership enrollment.

### How to Manage Leads

1. Go to **Leads** page from the sidebar
2. View leads as a **Kanban board** (drag-and-drop between stages) or **Table** view
3. Click **"Add Lead"** to create a new prospect
4. Fill in: Name, Email, Phone, Source, Score, Deal Value
5. **Drag cards** between pipeline stages to track progress
6. Click a lead card to view details, log activities, and update status
7. Mark as **Won** then click **"Convert to Client"** to create a member account

### Lead Pipeline Stages

| Stage | Description |
|-------|-------------|
| New | Fresh lead, not yet contacted |
| Contacted | Initial contact made (call/email/message) |
| Tour Scheduled | Gym tour booked |
| Tour Completed | Prospect visited the gym |
| Proposal Sent | Membership proposal/pricing shared |
| Negotiation | Negotiating terms or pricing |
| Won | Lead signed up as a member |
| Lost | Lead decided not to join |

### Lead Scoring

Leads are scored as **Hot** (very likely to convert), **Warm** (interested), or **Cold** (low engagement). Update the score based on interactions to prioritize follow-ups.

### Lead Activities

Log every interaction with a lead by clicking on the lead and adding an activity:
- **Call** — phone call notes
- **Email** — email sent/received
- **Tour** — gym tour details
- **Follow-up** — scheduled follow-up reminder
- **Note** — general note
- **Meeting** — in-person meeting
- **SMS** — text message

### Converting a Lead to Client

1. Move the lead to the **Won** stage
2. Click **"Convert to Client"**
3. A client account is automatically created with the lead's info
4. The client appears in the Clients page, ready for membership assignment

### Common Issues

**Q: Where do I find lead statistics?**
A: Go to **Leads** page — stats appear at the top (by stage, conversion rate, by source, by staff).

**Q: Can I import leads in bulk?**
A: Use the Data Migration tool to import leads from CSV/Excel.

### How to Generate Class Sessions

### Class Session Statuses

## Appointment / Personal Training Booking

Book 1-on-1 or small group sessions with trainers, with availability calendars and session packages.

### How to Create a Service

1. Go to **Appointments** page from the sidebar
2. Click the **Services** tab
3. Click **"Add Service"**
4. Fill in:
   - **Name** (e.g., "Personal Training", "Sports Massage")
   - **Duration** in minutes (e.g., 30, 45, 60)
   - **Price**
   - **Max Participants** (1 for 1-on-1, more for small groups)
   - **Category** (optional)
   - **Buffer Minutes** — gap between back-to-back appointments (e.g., 10 min)
5. Click **"Save"**

### How to Set Trainer Availability

1. Go to **Appointments** > **Availability** tab
2. Select a trainer (or trainers set their own)
3. For each day of the week, set:
   - **Start Time** (e.g., 09:00)
   - **End Time** (e.g., 18:00)
   - **Available** (on/off)
4. Click **"Save"**

### How to Book an Appointment

1. Go to **Appointments** > click **"Book Appointment"**
2. Select the **Service** (optional)
3. Select the **Trainer**
4. Select the **Date** — available time slots are shown based on the trainer's availability and existing bookings
5. Pick a **Time Slot**
6. Select the **Client**
7. Add **Notes** (optional)
8. Click **"Book"**

The system automatically:
- Checks the trainer's availability for the selected day
- Checks for conflicts with existing appointments
- Accounts for buffer time between appointments
- Shows only truly available slots

### Appointment Statuses

| Status | Description |
|--------|-------------|
| Booked | Appointment is confirmed |
| Confirmed | Staff/trainer confirmed the booking |
| Completed | Session was held — session package is auto-deducted |
| Cancelled | Appointment was cancelled (reason recorded) |
| No Show | Client didn't show up |

### Session Packages

Session packages let members pre-purchase a bundle of sessions:

1. Go to **Appointments** > **Packages** tab
2. Click **"Add Package"**
3. Select the **Client** and **Service**
4. Enter **Total Sessions** (e.g., 10)
5. Set **Expiry Date** (optional)
6. Click **"Save"**

When an appointment is marked as **Completed**, the system automatically deducts 1 session from the member's active package. Expired packages are not deducted.

### Common Issues

**Q: Why are no time slots showing?**
A: Check that the trainer has availability set for that day of the week. Also check for existing bookings or buffer time gaps.

**Q: What is buffer time?**
A: Buffer minutes (e.g., 10 min) are added after each appointment so the trainer has a break. A 60-min service with 10-min buffer means 70 minutes total per booking.

**Q: How are session packages deducted?**
A: Automatically when an appointment is marked "Completed". The oldest non-expired active package is deducted first.

**Q: Can clients book their own appointments?**
A: Yes. Clients can book from their app — they can only book for themselves.

**Q: Can a trainer see other trainers' appointments?**
A: No. Trainers only see their own appointments (and appointments where they are the client).

## NPS & Member Surveys

Create surveys, collect feedback, and track your Net Promoter Score (NPS).

### How to Create a Survey

1. Go to **Surveys** page from the sidebar
2. Click **"Create Survey"**
3. Fill in:
   - **Title** (e.g., "Monthly Satisfaction Survey")
   - **Type**: custom, nps, feedback
   - **Anonymous** (yes/no)
   - **Questions** — add multiple questions:
     - **Rating** (1-5 stars)
     - **NPS** (0-10 scale)
     - **Text** (free-form response)
     - **Single Choice** (radio buttons)
     - **Multiple Choice** (checkboxes)
4. Set **Start Date** and **End Date** (optional)
5. Click **"Save"** (saves as Draft)
6. Click **"Activate"** to make the survey live

### Survey Statuses

| Status | Description |
|--------|-------------|
| Draft | Created but not yet live |
| Active | Currently accepting responses |
| Closed | No longer accepting responses |
| Archived | Stored for reference |

### Viewing Survey Results

1. Go to **Surveys** page
2. Click on a survey
3. View the **Analytics** tab:
   - Response count
   - Per-question statistics (average rating, choice distribution)
   - NPS score breakdown (Promoters, Passives, Detractors)

### NPS (Net Promoter Score)

NPS measures customer loyalty on a 0-10 scale:
- **Promoters (9-10)** — Loyal members who will refer others
- **Passives (7-8)** — Satisfied but not enthusiastic
- **Detractors (0-6)** — Unhappy members at risk of leaving

**NPS Score** = % Promoters - % Detractors (ranges from -100 to +100)

View the latest NPS from the Surveys page or ask the chatbot: "What's our NPS score?"

### Common Issues

**Q: Can surveys be anonymous?**
A: Yes. Set the "Anonymous" toggle when creating the survey.

**Q: How do I see who hasn't completed a survey?**
A: Active surveys show a list of pending members who haven't responded yet.

**Q: Can I trigger surveys automatically?**
A: Yes. Set a trigger type (e.g., after class, after cancellation) to auto-send.
